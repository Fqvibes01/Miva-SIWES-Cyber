Part 1: Understanding Disk Images

A disk image is an exact, bit for bit copy of a storage device (like a hard drive or USB drive), including all its data, deleted files, and unallocated space. In digital forensics, creating a disk image is a critical first step because it allows investigators to analyze the evidence without ever touching the original device. This preserves the integrity of the original evidence. Benefits include preventing accidental modification, allowing verification through cryptographic hashes (like SHA-256), permitting multiple investigators to work on the same case simultaneously, and ensuring the evidence is admissible in court.

Task 2: Acquisition Using dd Command (Linux)
- Ran the command lsblk to list all block devices and identified the USB drive identifier.
- Ran the following command to create a bit-for-bit copy:
  sudo dd if=/dev/sdX of=~/usb_image.img bs=4M status=progress
- Parameters: if=/dev/sdX is the input (USB drive). of=~/usb_image.img is the output file. bs=4M sets the block size to 4 Megabytes to speed up the copy. status=progress shows real-time transfer speed and data copied.

Task 3: Acquisition via Network
Network acquisition involves capturing a disk image from a remote machine over a network connection. The main advantage is speed and efficiency, especially in large environments. It also allows for live acquisitions of running systems. However, the main challenges include network bandwidth limitations (large drives take a long time to transfer) and the risk of data alteration over a live network.
